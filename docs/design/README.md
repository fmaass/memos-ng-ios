# Design of record — the picture library

`photos-library-mockup.html` is the owner's interactive mockup of the Photos-style library (exported
2026-09-27 from the Claude artifact "Photos-style Library", made in another account, which is why
it lives here as a file); `photos-library-mockup.md` is its text export. Together with memos-ng plan
page 3929 (decisions 5, 8, 9, 10, 11, 12) they are the binding source for the native library
(WP-11, story MEMNG-583): every brief and gate prompt for that work names them, and an acceptance
criterion reads "matches decision N". Open the HTML in a browser to drive the mock; the text is
what a session without a browser reads.
